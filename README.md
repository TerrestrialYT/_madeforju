# Guwahati Coffee House | Premium Digital Storefront

A bespoke, highly interactive single-page website built for **Guwahati Coffee House**, a new specialty cafe located in Assam. 

Designed with a warm, cozy espresso-and-cream aesthetic, this project acts as a high-converting digital storefront focused on local SEO and driving foot traffic directly to their Google Maps location.

**Live Demo:** [View Live Site Here](https://terrestrialyt.github.io/guwahati-coffee-house/) 

## ✨ Premium Features & Interactivity

This site is built with a focus on tactile user experience and local business conversion:

* **Interactive Floating Beans:** A lightweight vanilla JavaScript event listener generates dynamic, upward-floating coffee beans whenever the user clicks the page.
* **Minimalist Preloader:** A timed, fade-out "Brewing..." reveal builds anticipation before the site fully renders.
* **Artisanal CSS Texture:** A nearly invisible SVG noise filter overlays the page, giving the digital screen the warm, physical texture of premium cafe menus.
* **Frictionless Conversion:** Primary CTAs skip the standard "menu" and drive users straight to the Google Maps pin for immediate navigation.
* **Bespoke UI Details:** Features a custom espresso-brown scrollbar and text-selection highlight to maintain complete brand immersion.

## 🛠 Tech Stack

* **HTML5:** Semantic, SEO-optimized markup.
* **Tailwind CSS:** Utility-first CSS framework (via CDN) for precise, responsive styling.
* **Vanilla JavaScript:** Custom logic for the preloader and cursor micro-interactions (No heavy frameworks).
* **AOS Library:** Scroll animation logic (via CDN).
* **Google Fonts:** 'Playfair Display' (Classic Headings) & 'Outfit' (Clean Body Text).

## 🚀 Deployment (GitHub Pages)

This project is built as a pure, single-file static website (`index.html`) optimized for maximum speed and easy hosting on GitHub Pages.

1. Create a new repository on GitHub and upload your `index.html` file.
2. Ensure the `logo.jpg` file is uploaded to the **root** folder, directly next to `index.html`.
3. Go to your repository **Settings**.
4. Navigate to **Pages** in the left sidebar.
5. Under "Build and deployment", set the **Source** to `Deploy from a branch`.
6. Under "Branch", select `main` (or `master`), leave the folder as `/ (root)`, and click **Save**.
7. Wait 1-2 minutes, and your live URL will appear at the top of the Pages settings screen.
